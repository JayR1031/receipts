| 1 | HIGH | **A quote that is not on the page gets verified when the page text is shorter than the quote.** `fuzz.partial_ratio(quote, body)` slides the *shorter* string along the longer one. When `body` is the shorter of the two, the page text is matched inside the quote. Example: an `ok=True` page whose text is `"Pricing"` "verifies" the made-up quote `"Our pricing is free forever for every team"` as `quote_fuzzy` with a score of 100. That breaks the spec rule that a claim may only cite what this run fetched. No test covers a page shorter than the quote: tests :106 and :116 both use quotes shorter than the page. | `src/receipts/verify/rules.py:118`. `uv run python -I /private/tmp/claude-501/-Users-jay-Projects-receipts/fb24ba33-869d-4806-aaae-f0de1be3763e/scratchpad/l2_probe.py` exit 0 printed `short body: True quote_fuzzy fuzzy match: partial_ratio=100.0 >= 90` | Only try the fuzzy match when `len(quote) <= len(body)` and treat anything else as a miss. Alternatively, use `fuzz.partial_ratio_alignment` and require the aligned span to cover the whole quote. Add a red-first test with a short `ok=True` page and a longer quote that is not on it. |
