## Public names for `routes` and `wiring`

- `receipts.auth.provider` (no `__all__`):
  - `IdentityProvider`, a Protocol with `async exchange(code: str, *, redirect_uri: str, code_verifier: str) -> IdTokenClaims`. It returns claims whose signature is verified but which are **not yet validated**: call `oidc.validate_claims(claims, client_id=..., nonce=round_trip.nonce, now=<aware>)` next. It raises `AuthError` with `check` set to `token_exchange`, `jwks` or `id_token`.
  - `GoogleIdentityProvider(client_id: str, client_secret: SecretStr, *, http: httpx.AsyncClient | None = None)`.
  - `TokenResponse`.
  - Constants: `TOKEN_ENDPOINT`, `JWKS_URL`, `HTTP_TIMEOUT` (10.0), `ID_TOKEN_ALG` (`"RS256"`).
- `receipts.auth.fake` (no `__all__`):
  - `FakeIdentityProvider(claims: IdTokenClaims | Mapping[str, IdTokenClaims] | None = None)`, with a mutable `claims_by_code: dict[str, IdTokenClaims]` and `calls: list[ExchangeCall]`. An unknown code raises `AuthError("token_exchange")`.
  - `ExchangeCall(code, redirect_uri, code_verifier)`, a frozen dataclass.
  - `fake_claims(*, sub, email, aud, nonce, iss, exp) -> IdTokenClaims`.
  - Constants: `FAKE_CODE`, `FAKE_SUB`, `FAKE_EMAIL`, `FAKE_CLIENT_ID`, `FAKE_NONCE`, `FAKE_ISSUER`, `FAKE_EXP` (2100-01-01 UTC).
- `receipts.auth/__init__.py` does not re-export these names; it was outside this task's scope.
